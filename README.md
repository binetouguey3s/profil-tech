### Application de formulaire d'integration pour mieux se faire connaitre

## ProfilTech

ProfilTech est une application web simple qui permet de remplir un formulaire d'integration pour creer un profil personnel.
Le formulaire aide a mieux connaitre une personne a travers son identite, son contact, son domaine technique, son rythme de travail, ses centres d'interet et sa presentation.

# Fonctionnalites

-- Formulaire avec plusieurs sections : identite, contact, profil technique, rythme de travail, centres d'interet et presentation.
-- Validation des champs obligatoires en JavaScript.
-- Messages d'erreur affiches sous les champs incorrects.
-- Compteur de caracteres pour la presentation.
-- Affichage d'une carte recapitulatif quand le formulaire est valide.
-- Design responsive adapte aux petits ecrans.
